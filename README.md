## 各ファイルの概要

### 1. データの読み込みと基本操作 (`Pandas_Step1.ipynb`)
Pandasライブラリを用いた2次元表形式データ（DataFrame）の扱い方の基礎を実装。
- **学習内容**:
  - `pd.DataFrame` を用いた構造化データ（表）の生成
  - `.loc`（ラベル指定）および `.iloc`（インデックス番号指定）によるデータの部分抽出（3行3列の切り出し）
  - ループ処理を用いない列同士の「ベクトル演算（ブロードキャスト機能）」による新しい特徴量（総客数）の生成
