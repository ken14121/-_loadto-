# 学習の流れ
このリポジトリでは、データ解析を「表の扱い」から「可視化」、「回帰分析」へと少しずつ段階的に学んでいきます。

## 1,データの読み込みと基本操作(データ解析1_0529.ipynb)

Pandasライブラリを用いた2次元表形式データ（DataFrame）の扱い方の基礎を実装。

学習内容:

・pd.DataFrame を用いた構造化データ（表）の生成

・.loc（ラベル(名前)指定）および .iloc（インデックス番号指定）によるデータの部分抽出（3行3列の切り出し）

・ループ処理を用いない列同士の「ベクトル演算（ブロードキャスト機能）」による新しい特徴量（総客数）の生成

## 2,回帰分析の基礎(データ解析1_0601.ipynb)

Pandasライブラリを用いた2次元表形式データの扱い方の基礎を復習、グラフ作成、平均値や予測値の分析を学習

学習内容:

・散布図による相関の確認

・平均値を基準にした4象限の見方

・np.polyfit() を使った単回帰分析

・傾きと切片を用いた未来予測

## 3,重回帰分析への発展(データ解析3_0605.ipynb)

Pandasライブラリを用いた2次元表形式データの扱い方の基礎を復習、グラフ作成、平均値や予測値の分析の復習、重回帰分析(複数の特徴量を利用する分析方法)の学習とPandasの使い方

学習内容:

・説明変数を1つから複数へ広げる

・sklearn.linear_model.LinearRegression を使った学習

・coef_ と intercept_ の確認

・予測値と誤差の確認
